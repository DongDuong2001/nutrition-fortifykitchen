## Existing `-dark` / `-on-dark` tokens

Six tokens are true dark-mode placeholders, all with **0 uses** (and no `.glass-tab` rule reads them): `--color-glass-tab-dark`, `--color-tab-teal-dark`, `--color-tab-orange-dark`, `--color-wash-overview-dark`, `--color-wash-explore-dark`, `--shadow-glass-tab-dark` (+ the 3 `--wash-alpha-*-dark`). Eight others are named `*-on-dark` or `*-dark` but mean "on the ink surface", not dark mode, and are in use: `--color-muted-on-dark`, `--color-on-dark`, `--color-surface-dark`, `--color-level-empty-dark`, `--color-track-on-dark`, `--color-press-on-dark`, `--color-cobalt-on-dark`, `--color-amber-on-dark` (the last is unused). Do not treat these as dark-mode variants; in dark mode the ink surfaces themselves change (hero #1C1C1E, toast #2C2C2E), so "on-dark" text stays white.

## Overrides outside @theme that also need a dark pair

`@media (prefers-contrast: more) { :root { ... } }` (globals.css 437-446) redefines `--color-card-border`, `--color-divider` (#B9B4AA), `--color-secondary` (-> `--color-secondary-strong`), `--color-scrim` (rgba(17,19,23,.55)), `--shadow-ring`, `--shadow-chip`, `--shadow-card` (ink at .32). A dark map needs its own "more contrast" row (proposed, no source: borders #8E8E93, scrim rgba(0,0,0,.75), rings rgb(255 255 255 / 0.4)). `:root { color-scheme: light }` (line 432) must become `light dark`. `--gradient-tile-rainbow` (line 383) is a token defined in :root, not @theme.

## Aliases that block a dark map

- `--color-text: var(--color-ink)`: dark needs text #FFFFFF while ink-as-surface stays a dark slab; cut the alias.
- `--color-macro-kcal-text: var(--color-cobalt)`: dark text is #5CB8FF (V3Compare MAC.energy), not the #2457F5 button blue; cut the alias.
- `--color-macro-*-text: var(--color-deep-*)` and `--color-macro-*: var(--color-sys-*)`, `--color-level-*: var(--color-sys-*)`, `--color-wash-home: var(--color-cobalt)`: safe, they inherit once sys/deep are mapped.
- `--color-ink` (bg 47 / text 24 / border 2), `--color-cobalt` (text 139 / bg 81 / outline 17 / ring 16 / border 22 / other 5) and `--color-on-accent` (text 51, plus white-on-destructive) each play several roles that go different ways in dark. These three are the real token-design work.
