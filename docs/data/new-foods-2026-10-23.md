# New foods, 23/10/2026

For Hao's server import (Dong's importer, unchanged). Data only: `docs/data/new-foods-2026-10-23.json`, **36 rows, all new** (no live row is updated). No web, migration, API or database change; nothing imported.

Values per 100 g as eaten, rounded as in `round_nutrients.py` (energy, protein, carbs, fat, fiber to 1 decimal; every other nutrient to 3 significant figures). Source order: NIN (Bảng thành phần thực phẩm Việt Nam) → USDA (SR Legacy 2018-04, FNDDS 2024-10-31) → product labels (source `label`, with the page URL and the date read) → recipe_calc from live rows. A nutrient with no source is left out, never 0; nothing is estimated except the one row Hao asked for (MeatCool minced pork, assumed 90 % lean + 10 % fat), which is flagged as an estimate. `recipe_calc` rows keep a nutrient only when the ingredients that have it make up at least 90 % of the mass (the earlier recipe rows' rule); plain water counts 0 for every nutrient but keeps its grams (and the `water` value); salt is 0,6 % of the finished dish.

**Live catalogue read 23/10/2026** from `GET /api/v1/foods?limit=500&page=1..3`: **1,306 foods** (the 21/10 snapshot had 1,299: 7 rows were added since, among them Bánh khoai nướng Minh Hào). Every row below was checked there by name and by `source` + `source_id`: none exists, so the importer only inserts. Expected count after the import: **1306 + 36 = 1342**.

Portions: gram weights of USDA/FNDDS rows come from the source (FNDDS '1 item'); the cell/bowl weights of NIN rows are typical weights (NIN gives none) and are marked as estimates in each row's flags; recipe portions are the whole recipe.

Not rows (already live, skipped as asked): Mồng tơi (sống, nấu chín), Vịt kho sả gừng, Cháo đậu xanh, Cá diêu hồng, Bánh bao nhân thịt (NIN 1009), Bánh khoai nướng Minh Hào; also Xôi xéo (NIN 15073), Giò lụa (NIN 7069) and Bánh phở are live. ## Flags

**Sữa dê (tươi, nguyên kem)**

- 1 ly 200 ml = 206 g (tỷ trọng 1,03)
- Đối chiếu: NIN 10002 Sữa dê tươi cho 69 kcal, đạm 3,5 g, béo 4,1 g, carb 4,5 g, Ca 147 mg trên 100 g (USDA: xem bảng). Dùng USDA 171278 theo yêu cầu

- Lấy thêm các chất bản ghi có và danh mục có khóa: 11 axit amin (g), DHA 0, EPA 0, caffeine 0, rượu 0. Không có omega-3 tổng trong bản ghi nên để trống

**Nước dùng gà**

- Chén 250 g là khẩu phần thông thường (ước tính, không từ nguồn)

**Nước dùng bò**
