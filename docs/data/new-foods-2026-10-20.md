# New foods, 20/10/2026

For Dong's importer. Data only: `docs/data/new-foods-2026-10-20.json` (6 rows). No migration, no API or DB change was made. Values are copied from the USDA FoodData Central CSVs in `food-research/usda` (SR Legacy 2018-04, Foundation 2026-04-30) and rounded as in `round_nutrients.py` (energy, protein, carbs, fat, fiber to 1 decimal; every other nutrient to 3 significant figures). Nothing is estimated: a nutrient the source record does not have is left out, never 0 or null. Values are per 100 g of the edible part.

The live catalogue was read on 20/10/2026 from `GET /api/v1/foods` on lehongkhanh.vn: 1,273 foods. The server caps `limit` at 500, so `limit=5000` returned 500 and the catalogue was read in 3 pages (`page=1..3`, `limit=500`).

## Not added: no source has the data

- **Chân gà (sống)**: USDA has only "Chicken, feet, boiled" (FDC 171119); no raw record in SR Legacy, Foundation or the NIN table. The row is added as boiled only, so there is no raw/cooked twin yet. NIN 7108002 ("Thịt gà, ta, chân, đùi, luộc") is local-chicken leg meat, not feet, so it was not used. A raw row would need a yield factor, which is an estimate, so none was made.
- **Chân vịt**: no duck-feet record in SR Legacy, Foundation or NIN.
- **Nho đen**: no black-grape record. USDA has red/green European grapes, American slip-skin (FDC 174682) and muscadine (FDC 173040); NIN has "Nho ngọt, tươi" (NIN 5037, no colour). USDA does not name any of them black, and mapping one to "đen" would be a guess, so none was added. Hao decides; the nearest candidate is FDC 174682 (American type, slip skin).
- **Bào ngư (hấp)**: USDA has raw (FDC 174212) and fried (FDC 174213) only. Raw is added; fried is not, as it was not asked for and "chiên" never joins the twin.
- **Dish chân gà sả tắc**: no USDA or NIN record for it, so no row (the app's recipe rows are computed from ingredients and are not a source).

## Twins and yield

Da gà (sống) and Da gà (nướng) follow the Cánh gà (sống)/(nướng) precedent: "nướng" is a prepared state, so it is its own list row and does not join the raw one in `lib/food-twins`. Chân gà (luộc) and Bào ngư (sống) have no other state in the data, so each stays a single row. None of the six ids is in `raw-cooked-pairs`, so `lib/yield` goes by name and group for them.

## How Dong imports this

From `apps/api`, with `DATABASE_URL` set. Dry-run first: it parses the file and prints the completeness report, and writes nothing.

```bash
go run ./cmd/importfoods --dry-run --file ../../docs/data/new-foods-2026-10-20.json
```

Then the real import (upsert on `source` + `source_id`, so a re-run is safe; portions are replaced per food):

```bash
go run ./cmd/importfoods --file ../../docs/data/new-foods-2026-10-20.json
```
